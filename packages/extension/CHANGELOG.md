## 0.1.0 — 2026-04-24

- Initial release.
- Custom editor for PNG, JPG, WebP, and AVIF with live Before/After preview.
- Crop (8-handle overlay), resize (aspect lock, px/%), compress (format + quality).
- Compare modes: Original / Slider / Preview.
- Zoom and pan on the canvas.
- Save & Replace moves the original to the system Trash.
- Activity Bar sidebar with tree view of every image in the workspace.
- User settings for default compare mode, default quality, and excluded folders.
